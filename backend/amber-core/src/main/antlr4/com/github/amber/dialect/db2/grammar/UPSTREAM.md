# Db2 grammar

| | |
|---|---|
| Source | Written for Amber from the IBM Db2 12.1 for LUW SQL Reference (https://www.ibm.com/docs/en/db2/12.1); no IBM code was used. Replaces the grammars-v4 `sql/db2` grammar, which could not parse basic statements (schema-qualified names, CREATE TABLE columns, INSERT VALUES, CREATE VIEW, DROP, SQL PL). |
| License | Apache-2.0 (same as Amber) |
| Written | 2026-11-07 |

Keyword tokens and the `non_reserved_keyword` rule are generated by
`backend/amber-core/tools/db2/generate_keywords.py`. `SKIP`, `MODE` and `HIDDEN` are named `SKIP_`,
`MODE_` and `HIDDEN_` to avoid clashes with ANTLR and generated Java.

Known gaps (see the corpus in `amber-test/src/test/resources/corpus/db2/amber`):

- `XMLTABLE(… COLUMNS …)` and `JSON_TABLE(… COLUMNS …)` in FROM; JSON clauses `FORMAT JSON`,
  `ABSENT/NULL ON NULL`, `… ON ERROR`, `WITH WRAPPER`, `IS JSON`.
- Oracle-compatibility syntax: `CREATE PACKAGE`, PL/SQL blocks, `:=`, `%TYPE`/`%ROWTYPE`, `(+)`.
- Typed tables/views (`OF type`), dereference `->`, method calls, `TREAT`.
- CREATE/ALTER of event monitors, workload management objects, audit/security objects, federation
  objects (NICKNAME, SERVER, WRAPPER, USER MAPPING), partition groups and a few others; ALTER SCHEMA,
  ALTER TYPE, ALTER STOGROUP.
- Embedded-SQL-only syntax (DECLARE SECTION, INCLUDE, WHENEVER, SQLDA) and most CLP commands
  (RUNSTATS, REORG, EXPORT, IMPORT, LOAD and DESCRIBE are accepted with unstructured arguments).
- `SELECT COUNT(*) days FROM t` reads `days` as a labeled duration; write `AS days`.
